# HomeNet — Кроссплатформенный мессенджер на C# и Avalonia UI

Кроссплатформенный клиент-серверный мессенджер с локальным кэшированием и двусторонней синхронизацией данных, развернутый на Linux VPS.

---

## 🚀 Ключевые особенности и архитектура

* **Кроссплатформенный клиент (Avalonia UI + MVVM):** Проект мигрирован с WPF на Avalonia UI с прицелом на дальнейший порт под Android и Linux.
* <img width="1445" height="995" alt="image" src="https://github.com/user-attachments/assets/6cd9f9ba-8067-486f-b8ef-033901403bf5" />

* **Собственный генератор SQL-диалектов (`DatabaseDialect`):** Единый интерфейс работы с данными без тяжелых ORM, поддерживающий генерацию параметризованных запросов под PostgreSQL (на сервере) и SQLite (на клиенте).
* **Синхронизация данных и защита от дублей:**
  * **Идемпотентность:** Генерация `GUID` на стороне клиента защищает сервер от создания дублей при сетевых сбоях и повторных запросах.
  * **Optimistic UI и порядок доставки:** Последовательная очередь отправки (FIFO) для мгновенного отклика интерфейса *(в разработке)*.
  * **Синхронизация удалений:** Использование паттерна *Tombstones* («таблица надгробий») для корректного удаления записей на всех устройствах *(в разработке)*.
* **Изоляция окружений (`Debug` / `Release`):** Раздельные конфигурации и локальные базы SQLite для безопасной отладки и работы с удалённым сервером.

---

## 🛠 Технологический стек

* **Язык и платформа:** C#, .NET
* **Клиент (Frontend):** Avalonia UI, XAML, MVVM
* **Сервер (Backend):** ASP.NET Core
* **Базы данных:** PostgreSQL (сервер), SQLite (локальный кэш клиента)
* **Инфраструктура:** Linux VPS, SSH (аутентификация по ключам), UFW

---

## 🏗 Схема работы

```text
[Клиент А: Avalonia + SQLite]  <--->  [Сервер на Linux VPS: C# + PostgreSQL]  <--->  [Клиент Б: Avalonia + SQLite]
```
